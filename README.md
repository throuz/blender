# 25–28 坪兩房住宅展示

主要交付檔為 `2br_sales_ready.blend`。場景依權狀 25–28 坪兩房產品定位製作，淨室內約 59.7 平方公尺、室內完成高度 2.9 公尺。

## 必要輸出

- `2br_living_verified.png`：客餐廳主視覺
- `2br_kitchen_final.png`：廚房視覺
- `2br_master_final.png`：主臥視覺
- `2br_floorplan_verified.png`：俯視格局圖

## 資產與授權

`assets/` 內的 HDRI、PBR 貼圖及部分家具模型來自 Poly Haven，依 CC0 授權使用。場景中保留來源資產，方便後續重新連結與調整。

## 渲染

場景預設使用 Eevee 方便編輯。最終室內圖使用 Cycles 路徑追蹤與降噪；色彩管理採 AgX Medium High Contrast。
